# DSMC Tools — Expansion Plan

This document outlines proposed new modules and features for the `ctfl_tools/DSMC` package.
Each section describes what the feature does, what it contains, and how it integrates with
the existing `Flow` / `Mixture` / `Species` stack.

**`Species.gamma` note:** The current property uses fully-excited classical equipartition
(`f = 3 + rotdof + vibdof`, `γ = (f+2)/f`). This is the physically correct limit for
hypersonic conditions (`T >> θ_vib`) where vibrational modes are fully excited.
A temperature-dependent `gamma_eff(T)` will be provided in the Thermo unit (§5.2)
using the SHO ζ_vib(T) formula. `Species.gamma` stays unchanged as the hypersonic default.

## 1. SPARTA Input Script Writer (`sparta_writer.py`)

**Goal:** Programmatically generate a complete, valid SPARTA `.input` file from Python objects
rather than hand-edited templates. Connects to the Thermo unit (§5) to automatically select
vibration mode, collision parameters, and embed reaction file references.

### Rationale

Every input file in `experiments/` shares the same structural skeleton (box, grid,
species/mixture, collision model, computes, dumps, run). SPARTA's `variable` system is
perfect for a template approach — all runtime values can be declared as variables at the top
and referenced with `${}` throughout.

### Proposed API

```python
writer = SPARTAInputWriter(
    flow=flow_free,
    domain=domain,               # see §3
    surface="cyl.surf",          # or None for open-domain
    collision_file="collision.list",
    reaction_file="air5.react",  # or None; generated by §6
    vibrate_mode="discrete",     # "discrete" | "continuous" | "none"
)
writer.set_grid(ncells_x=531, ncells_y=478, ncells_z=1)
writer.set_simulation(
    timestep=0.1 * tau,
    warmup_steps=warmup,
    samples=10000,
    sample_freq=5,
)
writer.write("case.input")
```

### Implementation plan

1. **`SPARTAInputWriter` class** in `sparta_writer.py`.
2. Build the file in ordered sections, each a method returning a list of lines:
   - `_header()` — seed, dimension, units, boundary
   - `_box()` — `create_box` from domain bounds
   - `_grid()` — `create_grid` + `balance_grid`
   - `_global()` — `global nrho`, `global fnum`, `global vstream`, `global temp`
   - `_timestep()` — `timestep`
   - `_species()` — `species` command + `mixture` fractions + `tvib` (if discrete)
   - `_surface()` — `read_surf` + `surf_collide` + `surf_modify` (skipped if no surface)
   - `_collide()` — `collide vss` + `collide_modify`
   - `_vibrate()` — `vibrate discrete` or `vibrate continuous` (conditional)
   - `_react()` — `react` command + reaction file reference (conditional)
   - `_computes()` — standard thermal/grid computes (Tt, Tr, Tv, nrho_species)
   - `_fixes()` — `ave/grid`, optional `ave/surf` for heat flux
   - `_dumps()` — grid and surf dump commands
   - `_run()` — warmup + production `run` commands
3. `fnum` and `nrho` are derived from the `Flow` object at write time.
4. `heat_flux=True` appends ke/erot/evib/etot computes and `ave/surf` fix.
5. `vibrate_mode="discrete"` adds `tvib` to the `mixture` line and emits
   `vibrate discrete` — this is required when using quantized vibrational energy
   (Ch. 7 §7.3.3). The Thermo unit's `theta_vib` value feeds directly here.
6. Support optional grid adaptation block (`fix adapt`) for production runs.
7. Boundary condition string (`o o p`, etc.) passed explicitly.

### Notes / open questions
- Two-pass mode for pre-adapted grids (`write_grid` / `read_grid` workflow)?
- Validate that mixture mole fractions sum to exactly 1 before writing.
- `tvib` on the mixture line is only needed when `vibrate discrete` is active.

## 2. Surface File Module (`surf.py`)

**Goal:** Read, validate, visualize, transform, and write SPARTA `.surf` files from Python.

### Rationale

Several scripts already contain `scale_surface_file` helpers.
`Pre-Processing-Geometry-Scripts/stl2surf.py` has more complete geometry utilities (normal
checking, plotting, deduplication, snap-to-box). These should be consolidated into a single
`Surf` class.

### Proposed API

```python
surf = Surf.read("cyl.surf")
surf.check_airtight()
surf.check_normals()
surf.fix_normals()
surf.check_inside_domain(domain)
surf.plot(ax=None, show_normals=False)
surf.scale(factor)
surf.translate(dx, dy, dz=0)
surf.snap_to_box(domain, tol=1e-7)
surf.write("cyl_scaled.surf")
surf = Surf.from_stl("geometry.stl", scale=1e-3, mode='3d')
```

### Implementation plan

1. **`Surf` class** in `surf.py`.
2. Internal representation: `pts` (N×3 numpy array), `elements` (M×2 for Lines / M×3
   for Triangles), `mode` (`'2d'` or `'3d'`).
3. **Airtight check (3D):** edge-to-face adjacency map; every edge must appear in exactly
   2 triangles. Report boundary (once) and non-manifold (3+) edges.
4. **Normal check:** for each triangle, compute N = (p2-p1)×(p3-p1) and dot with centroid.
5. **Visualization:** matplotlib line plot (2D) or `Poly3DCollection` (3D).
6. **STL reader:** absorb `read_stl` + `dedup` + `quantize_points` from `stl2surf.py`.
7. `scale_surface_file` in experiment scripts replaced by `surf.scale(f); surf.write(o)`.

### Notes
- 2D `.surf` (Lines) reader still needed for legacy files even if all active cases are 3D.
- `pyvista` optional via `try/import` guard.

## 3. Domain Class (`domain.py`)

**Goal:** Encapsulate the simulation box, grid parameters, and derived quantities (fnum,
flow-through time, simulation schedule) — replacing scattered copy-pasted functions across
experiment scripts.

### Proposed API

```python
domain = Domain(
    xlo=-0.0375, xhi=0.0,
    ylo=0.0,     yhi=0.03375,
    zlo=-7.5e-5, zhi=7.5e-5,
)
domain.set_grid_from_mfp(flow_free, n_mfp=2)
domain.set_grid(ncells_x=531, ncells_y=478, ncells_z=1)
domain.compute_fnum(flow, n_ppc=15, flow_volume=sparta_reported_vol)
schedule = domain.simulation_schedule(
    flow_free=flow_free,
    flow_shock=flow_shock,
    warmup_factor=5,
    samples=10000,
    sample_freq=5,
)
domain.print_summary(flow_free, flow_shock)
domain.save("cyl_domain.json")
domain = Domain.load("cyl_domain.json")
```

### Implementation plan

1. **`Domain` dataclass** — fields: `xlo, xhi, ylo, yhi, zlo, zhi`, `ncells_x/y/z`.
2. **`SimulationSchedule` dataclass** — `dt, warmup_steps, sample_freq, samples, total_steps`.
3. `domain.volume` property.
4. `domain.set_grid_from_mfp(flow, n_mfp)` — `ncells = round(len / (n_mfp * mfp))`.
5. `domain.compute_fnum(flow, n_ppc, flow_volume=None)` — `fnum = n * V / (N_cells * n_ppc)`.
6. `domain.flow_through_time(u)` and `domain.flow_through_steps(u, dt)`.
7. `domain.print_summary(...)` consolidates `print_flow_properties` + `print_grid_plan`.
8. `domain.check_surf_inside(surf)` delegates to `Surf.check_inside_domain(self)`.

### Notes
- `compute_fnum` should accept either pre- or post-adapt cell count from SPARTA output.
- `Domain` can hold the surface file reference so `SPARTAInputWriter` pulls from one object.

## 5. Thermochemistry Unit (`thermo.py`)

**Goal:** A pre-processing calculator for all nonequilibrium thermochemistry quantities
needed to set up and validate SPARTA simulations. This is a pure Python module — SPARTA
runs the actual physics at simulation time. The Thermo unit computes parameters, validates
them, and feeds them into `SPARTAInputWriter` and `Domain`.

**Textbook basis:** Boyd & Schwartzentruber, Chapters 3, 4, 6, 7; Appendices A–D.

### 5.1 Partition Functions

The total partition function factors as `Q = Q_tr × Q_rot × Q_vib × Q_el` (Eq. 3.101-3.103).
For equilibrium constants and backward rates only the internal partition functions matter
(Q_tr cancels in the ratio for dissociation/exchange, or contributes a density-dependent
factor for recombination).

**Translational (Eq. 3.86):**
```
Q_tr(m, T, V) = V × (2π m k T / h²)^(3/2)
```

**Rotational — classical continuous limit (Eq. 3.123):**
```
Q_rot(species, T) = T / (σ × θ_rot)
```
where `σ = 1` for heteronuclear (NO), `σ = 2` for homonuclear (N₂, O₂).

**Vibrational — SHO (Eq. 3.127):**
```
Q_vib(species, T) = 1 / (1 - exp(-θ_vib / T))
```

**Electronic (Eq. 3.115):**
```
Q_el(species, T) = Σᵢ gᵢ exp(-θᵢ / T)
```
Electronic state data hardcoded in `thermo.py` for five-species air (from Ch. 3 §3.5):
- N:  `g₀=4` (ground state ⁴S); first excited at θ₁=28,000 K — negligible for aerospace
- O:  `g₀=5` (³P₂), `g₁=3` at θ₁=228 K, `g₂=1` at θ₂=326 K; next at 23,000 K
- N₂: `g₀=1` (X¹Σ⁺ᵍ); first excited at 71,000 K — Q_el ≈ 1
- O₂: `g₀=3` (X³Σ⁻ᵍ), `g₁=2` at θ₁=11,900 K
- NO: `g₀=2` (X²Π), `g₁=2` at θ₁=174 K (doublet ground state — important even at low T)

```python
EL_STATES: dict[str, list[tuple[int, float]]] = {
    "N":  [(4, 0.0)],
    "O":  [(5, 0.0), (3, 228.0), (1, 326.0)],
    "N2": [(1, 0.0)],
    "O2": [(3, 0.0), (2, 11900.0)],
    "NO": [(2, 0.0), (2, 174.0)],
}

def q_tr(m: float, T: float, V: float) -> float: ...
def q_rot(species: Species, T: float) -> float: ...    # uses species.rottemp
def q_vib(species: Species, T: float) -> float: ...    # uses species.vibtemp
def q_el(species_id: str, T: float) -> float: ...      # looks up EL_STATES
def q_int(species: Species, species_id: str, T: float) -> float:
    """Q_rot × Q_vib × Q_el — the internal partition function."""
```

**Note on atoms:** Atoms have no rotational or vibrational modes. `q_rot` and `q_vib`
return 1.0 for atoms (rotdof=0 check). Electronic partition function is the only internal
mode.

### 5.2 Internal Energy and Specific Heat Properties

**Vibrational degrees of freedom — SHO (Eq. 3.132 / D.11):**
```
ζ_vib(θ_vib, T) = 2(θ_vib/T) / (exp(θ_vib/T) - 1)
```
Limits: ζ_vib → 0 as T → 0; ζ_vib → 2 as T → ∞ (matches classical `vibdof=2`).

**Specific vibrational energy (Eq. 3.128):**
```
e_vib(θ_vib, T) = R θ_vib / (exp(θ_vib/T) - 1)
```

**Rotational energy — classical (Eq. 3.124):**
```
e_rot(T) = R T   (for ζ_rot = 2 diatomics)
```

**Temperature-dependent γ (Eq. 3.126 generalized):**
```python
def gamma_eff(species: Species, T_tr: float, T_vib: float | None = None) -> float:
    """
    γ(T) using SHO vibrational DOF.
    T_vib defaults to T_tr (equilibrium). Set T_vib=0 to freeze vibration entirely.
    At T_vib >> θ_vib: ζ_vib → 2, matches Species.gamma (the hypersonic default).
    """
    zv = zeta_vib(species.vibtemp, T_vib or T_tr)
    f = 3.0 + species.rotdof + zv
    return (f + 2.0) / f
```

**Vibrational temperature from mean energy (Eq. D.9 — SHO):**
```
T_vib = θ_vib / ln(1 + k θ_vib / <ε_vib>)
```
Used for post-processing SPARTA output when `<ε_vib>` is the sampled cell-average.

```python
def zeta_vib(theta_vib: float, T: float) -> float: ...
def e_vib(theta_vib: float, T: float) -> float: ...
def t_vib_from_energy(theta_vib: float, e_vib_mean: float) -> float: ...
def gamma_eff(species: Species, T_tr: float, T_vib: float | None = None) -> float: ...
```

### 5.3 Rotational Relaxation Models (Ch. 7 §7.2)

SPARTA uses Z_rot via the `collide_modify rotate` command. The Thermo unit computes Z_rot(T)
for validation plots and for selecting appropriate constant values in the input file.

**Constant Z_rot:**
```python
def z_rot_const(species: Species) -> float:
    return species.rotrel
```

**Parker model (Eq. 7.1):**
```
Z_rot(T) = Z_rot^∞ / [1 + (π^(3/2)/2)(T*/T)^(1/2) + (π²/4 + π)(T*/T)]
```
Parameters from `species.rotc1` (= Z_rot^∞) and `species.rotc2` (= T*).
Valid for N₂: Z_rot^∞ ≈ 18.1, T* ≈ 91.5 K.

```python
def z_rot_parker(species: Species, T: float) -> float: ...
def z_rot(species: Species, T: float, model: str = 'parker') -> float:
    """Dispatcher: 'const' | 'parker'."""
```

**NDD and Boyd models** are noted as future extensions (`birdc1`/`birdc2` fields are
already in `Species` for this purpose), but not implemented in the initial pass.

### 5.4 Vibrational Relaxation Models (Ch. 7 §7.3)

SPARTA uses Z_vib (or τ_vib) via the `collide_modify vibrate` command.
The Thermo unit computes τ_vib(T) and converts to Z_vib = τ_vib / τ_coll.

**Millikan-White (Eq. 7.12-7.13):**
```
p τ_vib^MW = p^atm × exp(A × T^(-1/3) - B - 18.42)
```
where `A = MWA`, `B = MWB`, `p^atm = 101325 Pa`, and the result gives `τ_vib^MW` in seconds.

For cross-species vibrational relaxation (molecule *s* colliding with collision partner *q*),
an effective MW pair must be specified. The standard mixing rule uses the geometric mean of
species-pair parameters (Boyd & Schwartzentruber §7.3.2).

**Park high-T correction (Eq. 7.14-7.15):**
```
τ_vib^HT = 1 / (σ_v n C_m)
σ_v ≈ 10⁻²¹ m²,  C_m = √(8kT/πm_r) mean relative speed
```
Applied when T > T_c (typically T_c ≈ 8000-12,000 K depending on species).

**Haas-Boyd high-T correction (Eq. 7.16-7.17):** Alternative form, useful when Park
σ_v data is unavailable.

**Composite τ_vib and Z_vib:**
```
1/τ_vib = 1/τ_vib^MW + 1/τ_vib^HT     (Park blending)
Z_vib = τ_vib / τ_coll
```

```python
def tau_vib_mw(species: Species, T: float, p: float) -> float: ...
def tau_vib_park_ht(species: Species, T: float, n: float) -> float: ...
def tau_vib(species: Species, T: float, p: float, n: float,
            ht_correction: str | None = 'park') -> float: ...
def z_vib(species: Species, T: float, p: float, n: float,
          tau_coll: float, ht_correction: str | None = 'park') -> float: ...
```

### 5.5 Equilibrium Constants (Ch. 3 §3.6, Ch. 4)

The equilibrium constant connects forward and backward rate coefficients via (Eq. 7.53):
```
K_e(T) = k_f(T) / k_b(T)
```

From statistical mechanics (Eq. 3.144 and Ch. 4), K_e is derived from the ratio of product
to reactant partition functions. For a dissociation reaction `AB + M → A + B + M`:
```
K_e(T) = [Q_int(A, T) × Q_int(B, T) / Q_int(AB, T)] × (2πm_r kT/h²)^(3/2) × exp(-D/kT)
```
where D is the dissociation energy and the translational term accounts for the new relative
translational degree of freedom of the atom pair. For exchange reactions, only internal
partition functions and the activation energy difference enter.

The `Reaction` dataclass mirrors the group's `.chem` file format exactly
(as seen in `air11species.chem`). Each line pair in that file is:
```
Reactant1 + Reactant2 --> Product1 + Product2 [+ Product3]
[Type] [Class] [DoF] [eps_a (J)] [Af (m³/s)] [eta] [delta_e (J)]
```

| Field | Column | Meaning |
|---|---|---|
| `rxn_type` | 1 | `D`=dissociation, `S`=recombination, `E`=exchange-fwd, `F`=exchange-bwd |
| `rxn_class` | 2 | `A` (TCE model class — only class used) |
| `dof` | 3 | C₃ in TCE probability; `ζ_rot/2 = 1.0` for diatomic dissociation, `0.0` otherwise |
| `eps_a` | 4 | Activation energy (J); equals bond dissociation energy D for D-type; `0.0` for S-type |
| `Af` | 5 | Arrhenius pre-exponential (m³/molecule/s) |
| `eta` | 6 | Arrhenius temperature exponent (negative for most dissociation) |
| `delta_e` | 7 | Net reaction energy (J); negative=endothermic, positive=exothermic |

**D/S linkage:** S-type rows carry the *same* `Af` and `eta` as their paired D-type row.
These are the *forward* dissociation parameters used in the Boyd partition function
recombination probability (Eq. 7.62). `eps_a = 0` for S since recombination has no
activation barrier.

**E/F linkage:** F-type rows have *independently fit* Arrhenius parameters. These are
explicit backward Arrhenius fits (the "Arrhenius fit" approach, valid 5,000–20,000 K).
See open question Q8 about upgrading F-type to the Boyd partition function method.

```python
@dataclass
class Reaction:
    reactants: list[str]    # primary reactants, e.g. ["N2", "N"] — excludes third body
    products: list[str]     # products, e.g. ["N", "N", "N"]
    third_body: str | None  # third-body partner for D/S; None for E/F
    rxn_type: str           # "D" | "S" | "E" | "F"
    rxn_class: str          # "A" (reserved for future model classes)
    dof: float              # C₃ in TCE probability (= ζ_rot/2 for D, 0.0 for E/F/S)
    eps_a: float            # activation energy (J)
    Af: float               # Arrhenius pre-exponential (m³/molecule/s)
    eta: float              # Arrhenius temperature exponent
    delta_e: float          # net reaction energy (J)

def k_forward(rxn: Reaction, T: float) -> float:
    """k_f(T) = A_f T^η exp(-ε_a / kT)  (Eq. 7.54)"""

def equilibrium_constant(rxn: Reaction, T: float, species_db: dict[str, Species],
                         V: float = 1.0) -> float:
    """K_e(T) from partition functions — exact, no Arrhenius fit needed."""

def k_backward(rxn: Reaction, T: float, species_db: dict[str, Species]) -> float:
    """k_b(T) = k_f(T) / K_e(T)  (Eq. 7.55)"""
```

### 5.6 TCE Chemistry Model (Ch. 7 §7.4-7.5)

The Total Collision Energy (TCE) model converts a rate coefficient in Arrhenius form
into a per-collision reaction probability. This is the standard DSMC chemistry model in SPARTA.

**TCE reaction probability (Eq. 7.21):**
```
P_react = C₁ (ε_coll - ε_a)^C₂ (1 - ε_a/ε_coll)^C₃ / ν_A,B
```

**Deriving TCE coefficients from the `.chem` file parameters:**

The `.chem` file stores `Af`, `eta` (= η), and `dof` (= C₃) directly.
C₁ and C₂ are derived at runtime from the collision pair's VHS parameter ω:

```
C₂ = η - ω + 0.5          (Eq. 7.27 — temperature exponent correction; requires pair ω)
C₃ = rxn.dof              (read directly from file: 1.0 for D-type, 0.0 for E/F/S)
C₁ = Af × Γ(ζ_T) / [Γ(C₂+1) × Γ(ζ_T-1+C₃)] × (m_r / 2k)^C₂
     where ζ_T = 5 - 2ω  (effective translational DOF in collisions, Eq. B.25)
```

For dissociation (D-type, Eqs. 7.27-7.29): ζ_T = 5-2ω, C₃ = 1.0 (dof column).
For exchange (E/F-type, Eqs. 7.34-7.38): ζ_T = 5-2ω, C₃ = 0.0 (dof column).
Both follow the same formula for C₁ and C₂; C₃ is what distinguishes them.

**VFD model (Eq. 7.42):** Vibrationally Favored Dissociation — adds a vibrational energy
weighting factor φ(ε_vib) that increases reaction probability for vibrationally excited
molecules, providing better agreement with state-specific rate data.

**Backward exchange reaction probability — Boyd partition function method (Eq. 7.60):**
```
P_back = Af T^ηf × [Π_p Q_p / Π_r Q_r] × 1 / (ν_A,B / n_AB)
```
This avoids the Arrhenius fit problem for backward rates (Fig. 7.8-7.10) by using the
exact equilibrium constant from partition functions (Ch. 3).

**Three-body recombination probability (Eq. 7.62):**
```
P_3B-react = n × Af T^ηf × [Π_p Q_p / Π_r Q_r] × 1 / (ν_A,B / n_AB)
```
where n is the total number density in the cell (used as the third-body density).

```python
def tce_coefficients(rxn: Reaction, pair: _CollisionPair,
                     species_db: dict[str, Species]) -> tuple[float, float, float]:
    """Derive (C1, C2, C3) from Arrhenius parameters. Eqs. 7.27-7.38."""

def tce_probability(rxn: Reaction, coeff: tuple, eps_coll: float) -> float:
    """P_react from total collision energy. Eq. 7.21."""

def vfd_probability(rxn: Reaction, coeff: tuple, eps_coll: float,
                    eps_vib: float, theta_vib: float) -> float:
    """P_react^VFD with vibrational energy bias. Eq. 7.42."""

def backward_probability_binary(rxn: Reaction, T: float,
                                 species_db: dict[str, Species], nu_AB: float,
                                 n_AB: float) -> float:
    """P_back for binary backward exchange. Eq. 7.60."""

def backward_probability_3body(rxn: Reaction, T: float,
                                species_db: dict[str, Species], nu_AB: float,
                                n_AB: float, n_total: float) -> float:
    """P_3B-react for three-body recombination. Eq. 7.62."""
```

### 5.7 Reaction Database Module (`reactions.py`)

The group's primary reaction mechanism is the 11-species air model (Park 1993), stored in
`air11species.chem`. The `reactions.py` module **parses this file** — it does not hardcode
the reaction parameters. This means adding or modifying reactions requires only editing
the `.chem` file, not touching Python code.

## 6. Species Dataclass Extension

The `Species` dataclass needs two new optional fields to support §5:

```python
@dataclass
class Species:
    # ... existing fields ...
    homonuclear: bool = False          # σ=2 in Q_rot; True for N2, O2
    dissociation_energy: float = 0.0   # D (J) — bond dissociation energy for molecules
```

- `homonuclear` determines the symmetry number σ in `q_rot` (Eq. 3.127 note):
  σ=1 for NO (heteronuclear), σ=2 for N₂, O₂ (homonuclear).
- `dissociation_energy` D is needed for equilibrium constant calculations (Eq. 3.144);
  it is the energy to dissociate the molecule from its ground state.
- Electronic state data lives in `thermo.EL_STATES` (hardcoded) rather than `species.json`
  to keep the JSON schema simple and because the electronic states for air species are
  well-established spectroscopic data.

## 7. Implementation Order (revised)

1. **`thermo.py` §5.1-5.2** — partition functions + internal energy (most foundational;
   feeds everything else). Add `homonuclear` and `dissociation_energy` to `Species`.
2. **`thermo.py` §5.3-5.4** — Z_rot (Parker) and Z_vib (Millikan-White) relaxation models.
   These are immediately useful for validating collision parameter choices.
3. **`domain.py` §3** — eliminates copy-paste across experiments; needed by §1.
4. **`surf.py` §2** — needed for Domain's `check_surf_inside` and by the writer.
5. **`sparta_writer.py` §1** — highest payoff once Domain and Surf exist; now also
   handles vibrate mode and reaction file reference from the Thermo unit.
6. **`reactions.py` §5.7** — `read_chem_file` parser + `write_chem_file` + `AIR11_REACTIONS`.
   Can be built and tested standalone against `air11species.chem`.
7. **`thermo.py` §5.5-5.6** — TCE/VFD probabilities and backward rate calculations.
   Depends on reactions.py for `Reaction` objects and `AIR11_REACTIONS`.
8. **`thermo.py` §5.7** — macroscopic property tools (Appendix D).
9. **Pre-Processing-Geometry-Scripts integration §4** — lower priority; `stl2surf.py`
   already works well standalone.

## Open Questions / Design Decisions

| # | Question | Recommendation |
|---|---|---|
| Q1 | Cross-species MW parameters — how to store? | Use separate `cross_species_mw.json` keyed by sorted species pair, or compute from mixing rule at runtime. | 
| Q2 | `q_tr` includes volume — how to handle for K_e ratio? | Factor Q_tr out explicitly; only pass V when needed for recombination K_e. |
| Q3 | TCE coefficient derivation (Eqs. 7.27-7.38) — which rotational DOF enter? | ζ_rot = rotdof from species; assumes classical rotation is always fully excited for T > 300 K (valid for air). |
| Q4 | VFD model or TCE only for initial reactions implementation? | Start with TCE (simpler, more widely validated); VFD can be added as `model='vfd'` flag. |
| Q5 | SPARTA's `react` file format — exact column specification? | Read from an existing `.react` file in `experiments/` and match the format exactly. |
| Q6 | Should `write_chem_file` validate TCE coefficient consistency? | Yes — optionally recompute C₁ and C₂ from Af/eta/ω and warn if they differ from what SPARTA would compute, catching unit or sign errors. |
| Q7 | Two-pass writer for pre-adapted grids? | Defer until a case requires it. |
| Q8 | E/F exchange backward rates: use explicit Arrhenius (current file) or Boyd partition function method? | File currently uses explicit Arrhenius fits for F-type (valid 5,000–20,000 K per Boyd §7.5.2). Boyd partition function method is more accurate at extreme T but requires electronic state data for all 11 species. Decide before implementing §5.6 backward probability functions. |
| Q9 | 11-species electronic state data: do we have g, θ data for all ions and e⁻? | EL_STATES in §5.1 currently covers only neutral 5-species air. Need to extend for N⁺, O⁺, N₂⁺, O₂⁺, NO⁺ before K_e / Boyd-method backward rates can be computed for ionized reactions. |
